# Corneux_Cinematch

Projet Cinématch de Romain Corneux.
L'objectif de cette application est de permettre à des groupes de 2 à 4 amis de trouver un film à regarder lors d'une soirée.
Chaque personne peut proposer des films qui seront ensuite classés en fonction des votes de chacun. 

# Lancement de Cinématch

    - npm install
    - npm run server
    - npm run dev
    - http://localhost:5173
